# Этап 23 — Исполнители, которых не видно в Subsonic и вебе

Версия 0.23.5.

## Симптом

Исполнители не отображаются и не находятся поиском, хотя альбомы и плейлисты работают.

## Что нашлось

Все запросы по исполнителям шли через владельца альбома (`albums.artist_id`).
Исполнитель попадал в список, поиск и `getArtist` только если был владельцем альбома.
Не попадали:

- гости сборников (`Guest One` на «Various Artists»);
- фиты (`Main Star feat. Helper`);
- исполнители треков без альбома.

В базе они есть, в тегах есть, но клиент их не видел.

## Что исправлено

**Исполнитель = владелец альбома ИЛИ автор живого трека.** Общий SQL-фрагмент
`_LIVE_LINKS` объединяет обе связи. Через него работают `list_artists`,
`count_artists`, `search_artists`, `get_artist`, `artist_albums`.

**Вторая поломка — моя регрессия из 0.23.4.** Числовой сдвиг (`+1 000 000 000`) в
`getIndexes` сломал переход в исполнителя: `getArtist` по такому id отвечал «не найден».
Сдвиг убран. Папка исполнителя теперь получает строковый префикс `ar-<id>` в
`getIndexes` и `getMusicDirectory`. Числовые id остаются альбомами. Тот же приём
уже используется для обложек (`al-`, `tr-`).

**Веб.** Исполнитель без альбома показывает «N тр.» вместо «0 альб.» — иначе это
выглядит как пустая плитка. Для этого добавлен `track_count` в ответ `/api/web/artists`.

## Проверено

- Сценарий с сборником, фитом и треком без альбома: все исполнители видны в
  `getArtists`, `getIndexes`, `search3`, в вебе.
- Каждый id из `getIndexes` открывается через `getArtist` (раньше падало).
- Обход по папкам: папка исполнителя → альбом → треки.
- Регрессионные тесты: гость и трек без альбома в списках и поиске;
  `getArtist` по id из `getIndexes`; альбом гостя в его карточке; папка исполнителя
  не совпадает с альбомом по номеру; `track_count` в вебе.
- Полный pytest, pyflakes, headless JS.

## Что проверить у себя

Пересканировать библиотеку **не нужно**: исполнители собираются из тегов треков при
скане, и связи уже есть в базе. Достаточно обновить сервер и очистить кеш клиента,
если он закешировал список исполнителей до обновления.
