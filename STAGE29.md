# Этап 29 — Обложка из файла в папке альбома

Версия 0.24.5.

## Что сделано

Если рядом с треками лежит картинка (`folder`, `cover`, `front`, `orig`, `pic`
в любом регистре; jpg, jpeg, jfif, png, webp, gif), обложка берётся из неё, а
не извлекается из тегов аудиофайла. Если файла нет — как раньше, из тегов.

При нескольких файлах порядок фиксированный: по приоритету имени, затем по
размеру (крупнее — обычно настоящая обложка, а не превью), затем по имени.
Порядок не зависит от выдачи каталога, поэтому обложка не «прыгает» между
проходами.

Поиск идёт в каталоге трека и, как запасной вариант, в родительском.

**Настройка.** `cover_prefer_folder_image` в разделе «Настройки», чекбокс
«Обложка: сначала файл в папке». Включена по умолчанию. Применяется сразу,
без перезапуска.

**Кнопка.** «Пересобрать обложки из папок» в разделе «Сканирование»: сбрасывает
кеш у альбомов, где в папке есть картинка, и запускает проход заново.
Остальные альбомы не трогает — у них в кеше верная картинка из тегов.

## Исправлено попутно

**Перезапуск фазы обложек терялся.** Перезапуск вызывался из блока `finally`,
а `start()` в этот момент видел, что задача ещё не завершена, и вместо запуска
снова ставил флаг перезапуска. Фаза после этого не запускалась. Затронуты были
не только обложки: любой повторный запуск, запрошенный во время работы.

**Пересборка блокировала worker.** Обход каталогов тысяч альбомов выполнялся
внутри цикла команд: heartbeat не писался, и супервизор мог поднять второй
worker. Теперь пересборка — стадия фазы обложек, отдельной задачей.
