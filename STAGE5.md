# Этап 5 — Наблюдение, обложки, прогресс

## Наблюдение за библиотекой
`watchfiles.awatch` → фильтр → очередь (дедупликация, потолок 2000) →
`Scanner.scan(mode="incremental", paths=…)`.

- Событие на каталог обходит **всё поддерево** рекурсивно (проверено: из двух
  файлов альбома debounce может отдать только один).
- `missing` помечается только внутри обойдённых поддеревьев.
- Путь вне `MUSIC_DIR` отбрасывается.
- Переполнение очереди → полный инкрементальный скан.
- `MTR_WATCH_POLL_MS` — период опроса (100…60000, по умолчанию 1000).

Настройки и измерения — в README, раздел «Наблюдение за библиотекой».

## Обложки
Источники по приоритету: встроенная (APIC / FLAC picture / covr / Ogg
metadata_block_picture) → файл в каталоге трека → файл в родительском каталоге
(`cover.jpg`, `folder.png`, `front.jpg`…). Тип определяется по сигнатуре, а не
по расширению: теги часто содержат PNG под именем `.jpg`.

- Кэш на диске в `COVERS_DIR`, метаданные в `cover_cache`.
- Имя файла содержит хэш содержимого: смена обложки даёт новое имя.
- Атомарная запись (tmp + rename).
- Обложки > 20 МБ отбрасываются.
- Для альбома обложка ищется у его треков; для трека — собственная, иначе
  обложка альбома, но под ключом трека не кэшируется.

## Subsonic `getCoverArt`
- `id`: `al-<id>` (альбом), `tr-<id>` (трек), голое число — id трека.
- `size` игнорируется: ресайз без Pillow невозможен, отдаём оригинал.
- Ошибки — **HTTP-статусы**: 400 для плохого id, 404 если обложки нет, 401 без
  авторизации. JSON-конверт здесь не используется (бинарный метод).
- `Cache-Control: public, max-age=86400`.

## WebSocket `/ws/scan`
- Авторизация через query `u/t/s` (те же правила, что у Subsonic); без неё
  соединение закрывается кодом 1008.
- Отправляет состояние раз в секунду, но только при изменении.
- Содержимое: состояние наблюдателя, число треков, последний скан.

## Проверено
- 346 тестов проходят, включая наблюдение, рекурсию, обложки, WebSocket.
- Живой процесс с `MTR_WATCH_POLL=1`: вложенный трек и удаление обработаны.
- CPU опроса замерен на 200 / 2 000 / 6 000 файлах (таблица в README).

## Ограничения
- Задержка появления трека: 3–5 с при настройках по умолчанию.
- Недописанный файл при копировании может быть отвергнут mutagen; следующее
  событие его переиндексирует.
- Нет ресайза обложек: клиенты на слабых устройствах получат оригинал.
- `/ws/scan` — только для чтения; управления сканом через него нет.
- Измерений CPU на 10 000+ файлах нет.
